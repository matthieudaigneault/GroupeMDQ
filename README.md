# Groupe MDQ — Mécanique mobile — V2

Site statique prêt pour GitHub Pages.

## Contenu
- `index.html` — page complète V2
- `logo-groupe-mdq.png` — logo
- `favicon.png` — favicon

## Positionnement V2
Le site cible deux segments :
1. particuliers qui veulent économiser du temps;
2. travailleurs autonomes et petites entreprises qui veulent réduire l'immobilisation de leurs véhicules.

Le message central est : **Votre flotte roule. Votre entreprise aussi.**

## Formulaire
Le formulaire utilise `mailto:` vers `info@groupemdq.ca`. Aucun service externe n'est requis pour cette V2.
Une prochaine version pourra brancher un vrai formulaire web et/ou un calendrier de réservation.

## GitHub Pages
1. Créer un dépôt GitHub.
2. Déposer les trois fichiers à la racine.
3. Settings → Pages → Deploy from a branch → `main` / `/root`.
4. Ajouter `GroupeMDQ.ca` comme domaine personnalisé dans GitHub Pages.
5. Configurer les DNS du registraire selon les valeurs indiquées par GitHub.

## À vérifier avant mise en ligne
- adresse courriel
- numéro de téléphone
- modalités fiscales / taxes
- assurances et mentions légales pertinentes
- territoire exact
- services effectivement offerts
